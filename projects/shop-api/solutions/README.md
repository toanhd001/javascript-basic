# Lời giải tham khảo

Mỗi file ở đây là phiên bản **hoàn chỉnh** của file cùng đường dẫn trong project.
Chỉ mở khi đã tự làm và chạy test (`npm run task -- <số>`) — so sánh với cách của bạn, đừng chép.

Người bảo trì: `npm run check-solutions` chép các file này đè lên một bản sao project rồi chạy toàn bộ test.
